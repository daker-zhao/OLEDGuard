# OLED Guard Pro

macOS 状态栏应用，用于保护 OLED 屏幕，防止烧屏。

## 功能介绍

### 核心保护机制
通过智能画面检测+键鼠行为判断，自动叠加纯黑遮罩关闭屏幕发光元件，不影响主屏或副屏操作，快速实现屏幕保护与烧屏延缓，兼顾使用体验与屏幕寿命。

### 主要功能模块

1. **递进检测模式**
   - 宽松检测：画面出现轻微变动即可打断休眠倒计时，适配日常轻量操作；若键鼠无活跃行为，自动判定为画面静态小动画，平滑切换至严格模式。
   - 严格检测：将屏幕划分为4×4（可自定义）检测网格，仅当画面变动区域≤2（可自定义）个网格时，启动息屏判断；同步记录键鼠静止时长，为强制模式提供依据。
   - 强制检测：专为观影/视频播放场景优化：网格内活动区域＞8（可自定义）个时，判定为视频播放，保持屏幕常亮；若键鼠静止且活动区域不足8（可自定义）个，直接触发黑屏保护。
   - 每种模式均可配置容忍时长和活跃门槛
   - 三种模式可以任意组合搭配

2. **视觉采样基准**
   - 采样灵敏度调节：提升画面检测精度，精准识别真实画面变化，大幅降低误判概率。
   - 巡逻频率配置
   - 分析分辨率选择

3. **进阶休眠策略（双轨）**
   - 初始唤醒频率：保持高频检测与标准噪点阈值，毫秒级快速唤醒，不耽误即时操作。
   - 深度节能时限：进入深度唤醒频率时限。
   - 深度唤醒频率：超出浅度睡眠时长后自动切换，降低检测频率、提升自定义噪点阈值，减少CPU占用，同时避免误触唤醒屏幕。
   - 双轨回退特赦机制：通过判断变化程度来筛选唤醒到宽松还是当前模式（依然采用激活网格阈值来判断）。

4. **快捷键保护墙（暂时存在Bug）**
   - 自定义保护快捷键
   - 触发后持续保护时间

5. **物理遮罩**
   - 状态栏遮罩（自动识别 macOS 状态栏）
   - Dock 栏遮罩（智能吸附边界）
   - 自定义四周遮罩
   - 预设方案保存与切换

6. **多屏幕支持**
   - 自动检测并选择目标屏幕
   - 独立配置不同屏幕

## 系统要求

- **macOS 14.0+** (Sonoma 或更高版本)
- 配备 OLED 屏幕的 Mac 设备

## 权限要求

首次启动时需要授权以下权限：

1. **辅助功能权限** (Accessibility)
   - 用于检测按键活动、隐藏鼠标等

2. **屏幕录制权限** (Screen Recording)
   - 用于视觉检测屏幕内容变化

## 适用人群

- MacBook Pro (配备 OLED 显示屏的用户)
- 外接 OLED 显示器的 Mac 用户
- 担心 OLED 屏幕烧屏问题的用户
- 需要长时间显示静态内容的用户

## 使用说明

1. 安装后应用会显示在菜单栏（状态栏）
2. 点击菜单栏图标打开设置界面
3. 根据需要配置检测模式和遮罩策略
4. 确保已授权必要的系统权限

## 注意事项

- 本应用仅适用于 OLED 屏幕，LCD/LED 屏幕用户无需使用
- 遮罩仅在检测到静止画面时自动显示
- 所有配置自动保存
